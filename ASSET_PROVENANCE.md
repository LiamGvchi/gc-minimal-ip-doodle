# Asset Provenance

The repository contains four original runtime assets created for this public Skill package, two prior AI-generated runtime assets, and two documentation examples. The package maintainer has explicitly authorized all of them for public inclusion.

## Method

- The four `original-*` illustrations were AI-assisted in concept development, then deterministically authored as original SVG geometry and rendered to PNG.
- No third-party image, artist reference, branded character, trademark, or named visual style was used as an input to the four `original-*` assets.
- The package maintainer declared on 2026-08-23 that `capybara-desk.png` and `anglerfish-bedside.png` belong entirely to the maintainer and are authorized for public distribution. Both files contain OpenAI C2PA provenance identifying `gpt-image 2.0` trained-algorithmic media; C2PA records generation provenance, not legal ownership.
- `black-anglerfish-before-after.jpeg` combines a maintainer-generated character image with its authorized doodle result.
- `yellow-kangaroo-watering.png` is an AI-generated output explicitly authorized by the package maintainer for public inclusion on 2026-08-23. It is a documentation example rather than a strict flat-fill acceptance reference.
- The SVG source files are included in `assets/source-svg/` so the construction can be inspected.
- The PNG files in `assets/style-references/` are the runtime style references.
- Files in `examples/` are documentation examples and are not required at generation time.
