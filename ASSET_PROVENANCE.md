# Asset Provenance

The bundled style-reference set contains four original assets created for this public Skill package and two prior AI-generated assets that the package maintainer explicitly authorized for continued inclusion on 2026-08-21.

## Method

- The four `original-*` illustrations were AI-assisted in concept development, then deterministically authored as original SVG geometry and rendered to PNG.
- No third-party image, artist reference, branded character, trademark, or named visual style was used as an input to the four `original-*` assets.
- `capybara-desk.png` and `anglerfish-bedside.png` contain OpenAI C2PA provenance identifying `gpt-image 2.0` trained-algorithmic media. Their inclusion is based on the package maintainer's explicit authorization; C2PA records generation provenance, not legal ownership.
- The SVG source files are included in `assets/source-svg/` so the construction can be inspected.
- The PNG files in `assets/style-references/` are the runtime style references.
